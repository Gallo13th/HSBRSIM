## 3. 关键工程结论

1. **人类战团（board-only）注入是有效的难度来源**：只换 board+tier、旧 board 归池、新实体 `pool_copies=0`、EID 重映射、不设 `ended_turn`（该座位仍行动）；开销 ~2.95µs/次引擎调用。
2. **注入必须验证生效**：本轮发现 `hsbg_engine` 解析到旧 clone 导致注入静默空转——已用 `site-packages/hsbg_engine.pth` + fail-fast + history 计数三重修复。
3. **分层 BC 有效**：`bc_type` 13.3 → 1.86、`bc_card` 8.08 → 5.33，且不拖累主目标（C0 持续改善）。
4. **难度与吞吐的取舍**：注入量减 45% 时 dec/s 不变 → 成本来自「更强战团→战斗更长」，不是注入本身；最终在 2+1 席注入下达到 ~6.4–7.4k dec/s。
