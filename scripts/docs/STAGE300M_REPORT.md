## 0. 一句话

300M stage 从 s73 精确续训，实际跑到 **287.01M / 300M（95.7%）** 因「642 分钟时间护栏」
正常收尾（非崩溃）；final 模型对 bot 的面板为 **rank 1.734 / top4 96.9% / win 47.7%**，
但 **长且强 bot 局 win 仍为 0/6**；human 面板与 s73 基本持平（final 6.281，最佳单点 200M 6.000）。

  s73/40M 同档或略好**，说明 300M stage 没有把 bot 能力练坏。
- 反例：同一 ckpt 若 **不加 move_guard**，win 掉到 22.7% —— bot 面板必须与训练配置
  一致（move_guard=1）才有可比性。
- `bot_strength_curves` 64 局（seed 830000，训练配置）：win 40.6%、rank 1.984；
  **长且强 bot 局 0/6 胜**、强 bot 子集 0/64 —— 即 **遇到 bot 滚雪球的长局仍打不过**。
  这与 s73/40M/90M/140M 的结论一致（长且强 win 0–25%）。

## 4. 结论

1. 300M stage 在 human 面板上没有可测提升（final 6.281 vs s73 ~6.2），最佳单点 200M 6.000；
   在 bot 面板上保持/略优于 s73（47.7% win / 1.73 rank），但 **长且强 bot 局仍 0 胜**。
2. **不给 bot 加强化倍数（k=1）**：模型在长且强 bot 局尚未稳定取胜，加 k 只会更难。
3. 下一阶段：
   - 默认打开 `--bot-panel-games 96`，每个 10M 点同时记录 bot rank/win + 加权 bot 指标；
   - 训练侧可 opt-in per-episode 权重（长度+bot 强度，loss 加权），当前不改；
   - human 面板继续保留作参考，但 bot 局 rank/长且强 win 作为主要判据；
   - 若下一段仍无提升，按 P2（anchor 调度）做单变量实验，不再混其它改动。

### 6.3 判定

判据（[B03_DESIGN.md](B03_DESIGN.md) §5.2）：bot rank ≤1.673 / top4 +3pp / 长强 win +10pp（n≥24）/ human 不劣化 >0.10。

- **长强子集反向：win −4.3pp（n=51，0.8σ），rank 2.140→2.059 略好** ⇒ 「长且强」无改善
- 死亡盘面强度 p50 783→757；tier5@t15 43.8%→41.9%

⇒ **判定：未达判据。点估计 rank/win 略优、长强无改善 —— 记为「无效（无回归）」**，B03 权重保留作后续起点。

### 6.4 评测口径教训（本段最重要的方法学结论）

- 96 局：rank **SE ≈ 0.10** —— 此前把 80–200M 的起伏读成「震荡趋势」属于误读
- 384 局：同一模型在两个 seed 块（620000–383 / 620384–767）上差 **0.08**（B01 1.893→1.813；B03 1.763→1.857）
- 768 局：**SE ≈ 0.036**；判定 Δ≈0.1 至少 768 局，Δ≈0.05 需 ~2000 局
- 评测**确定性**已验证：同 ckpt/局数/seed 逐位复现（1.8229 / 0.9792 / 0.4167）
- 反面教材：B03@300M 在 384 局上是 **−0.130（像达标）**，扩到 768 局变 **−0.043**
  ⇒ 以后判定一律 ≥768 局，且必须写清局数与 seed 区间

### 6.5 诊断：短板在「长局后期的盘面强度」

- 输掉的局里我方死亡盘面 Σ p50 = **757**；同期死局结束时 bot 席最强 Σ 均值 ≈ **3139**（B01 783 / 3439）⇒ **约 4× 差距**
- 长且强子集（turns≥17 且 bot 强度 top-25%）胜率 **15.7–20.0%**，与其余局 45–50% 形成断层
- 与 [ECONOMY_CEILING.md](ECONOMY_CEILING.md) 一致：当前引擎「升 tier / 凑三连 / 留强度」三选二，人类级强度不可达；
  但**引擎 bot 自己就能到 3000+** ⇒ 「bot 级后期强度」可达，是模型没学到，不是引擎不给
- B03 的 p90 人类盘面课程对这个短板**没有转移作用**（长强 −4.3pp）

### 6.6 下一步（B04 候选，待决策）

1. **A｜长局 loss 加权**：per-episode `w = 长度 × bot 强度`（α=β=0.5）抬高长强局梯度占比。最便宜；
   风险是若上限在「不会滚雪球」，重加权只是在放大噪声。
2. **B｜训练侧 fidelity 对齐**：B03 训练用 `--human-board-fidelity board`，评测用 `full`（`eval_panel.sh`）——
   注入席行为分布不一致；改成 `full` + 5 席 p0.90 与评测同分布，是最便宜的「分布错配」修复。
3. **C｜对手强度课程 / 自对弈**：`--opponent self`（8 席自对弈，代码已有）或冻结旧 ckpt 池，
   从分布上逼出后期强度；标准 AZ 解法，风险是吞吐与稳定性。
4. **不建议**：再调 lr / 课程进度 / 奖励系数（[ECONOMY_CEILING.md](ECONOMY_CEILING.md) §4 已逐条证伪）。
