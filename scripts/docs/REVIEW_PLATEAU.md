# 平台终审：6.34–6.45 的含义与唯一下一实验

日期：2026-10-31。范围：仅证据审阅与实验预注册；本次不启动训练、评测或 GPU 作业，仅新增本文档。下述规模是建议，不代表已执行。

> **一句话裁决：当前只能称为“固定旧面板上的统计未分辨区间、伴随显著强度缺口”，不能裁定真上限或同一局部最优；下一实验只选 D——冻结模型、独立分组 exam、扩容配对评测，先分开测量噪声、选点偏差与真实改善。**

## 1. 证据边界与纠偏

已阅读 [压力审计](<PRESSURE_AUDIT.md>) 与 [保真注入审计](<FIDELITY_INJECTION.md>)。训练曲线和过程数值取自本次委托，未逐条复核原始训练日志，也未读取逐局 rank，因此不能提供实测配对 CI。

| run | 提供的人类面板结果 | 终审解读 |
|---|---|---|
| s10 | 6.533→6.523→6.514→6.402→6.471 | 最佳是 **6.402，不是6.344**；不能说三次都碰到同一个6.34下界 |
| s12 | 6.371→6.344→6.402→6.441 | 多次查看同一512局面板，最小值有选点偏差 |
| s13 | 6.344→6.430，当前20M/预算120M | 只有两个点且预算未完成，不能据此判长期收敛 |

三条 run 的剂量/保真配置不同，不能作为“同一算法三个独立训练种子”的方差估计；同一评测 seed 反复使用，也不产生新的独立考试数据。两个四舍五入后的6.344不是动力学吸引子的证据。

压力已被证实极强，但“有压力”不蕴含“存在可被当前探索发现的改进动作”。~60%暴露仍不是评测的100%，并且要按**学习者实际对位命中率**核验，而非只看配置概率。bot rank约1.76和98% top4只证明对弱 bot 的饱和，不能代替人类代理任务的进步。

保真度需准确命名：训练开关 `full` 是**准完整可得字段注入**，不是真实完整状态。审计说明真实观测缺每随从 script counter/gems、attachments、玩家级 combat 等字段；“counters”标签包含可视关键词等扩展信息。+2.62pp是可信自有快照消融结果，真实管线对应+1.36pp，不能直接当作真实人类全库上的同等压力收益，更不是rank收益。原始数据还混有多个build，必须进入版本分层/隔离。

λ=0.995、早期权重0.319仅排除了“指数衰减几乎归零”；14.6%不是政策梯度有效信噪比，不能排除信用、价值偏差或探索瓶颈。无注入冻结轨迹也不等价于s13训练分布。因而A仍是假说，但尚无资格压过D。

## 2. 三种解释如何裁决

1. **评测分辨率不足：当前最强解释。** 差值0.101小于或约等于单模型SE；基线SE、配对协方差、源库聚类都未知，不能仅靠单点SE宣告显著或不显著。同seed可能大幅降低差分方差，也可能没有帮助，必须看逐局差值。
2. **操作意义上的平台：可以提出，尚未确认。** 预先固定训练预算、checkpoint选择规则和配置后，跨种子相对改善的90%等效CI完全落在[−0.10,+0.10]，才能说“在此预算/协议下无≥0.10量级变化”。不显著不等于等效。
3. **同一局部最优：证据不足。** 相近rank不代表相同策略，更不代表梯度局部最优。需独立策略分歧、学习信号及受控干预结果；仅比较三条标量曲线不能证明。
4. **真强度上限：不予裁定。** 即使严格等效，也只能限定到当前算法、数据、预算与代理环境；不能推出PPO、模型容量或真实游戏的理论上限。

## 3. 样本量：0.101到底需要多少局

定义改善 `G = rank_baseline − rank_candidate`，越大越好；目标差值δ=0.101。按题设512局的单模型SE `s=0.09…0.17` 作保守规划，两模型等方差、独立对照时：

`n_per_model = 512 × 2s² × (z_(1−α/2)+z_power)² / δ²`。

| 双侧α=0.05 | 每个模型局数 | 两模型合计 |
|---|---:|---:|
| 80% power | 约6,400–22,800 | 约12,800–45,600 |
| 90% power | 约8,600–30,500 | 约17,200–61,000 |

这些是**事前检出概率**，不是跑到该局数就一定显著。只要求在观测差值恰好0.101时95%CI刚好不跨0，约需3,200–11,200局/模型，但检验功效不足，不能作为推荐预算。

配对时直接用 `n = (z_(1−α/2)+z_power)² Var(D)/δ²`，其中 `D=rank_baseline−rank_candidate`。等方差下，上表乘 `(1−ρ)`：ρ=0.5时约减半；ρ未知不得预支收益。共同随机数按游戏/回合/座位等稳定键组织，策略分叉导致随机流不同仍可做按初始场景配对，但不能假定后续逐动作RNG完全相同。

若源对局被重复抽样，局间存在聚类，需用聚类/交叉层级方差和有效样本量，不能把重播种数或逐回合数当独立局数。源库泛化误差无法通过无限重播同一源帧消除。还有一个核验点：rank在[1,8]时512个IID样本的SE上限约0.155；0.17若确为“SE”，需查清是聚类修正、有效n下降，还是CI半宽/其他指标误标。上述仍按题设保守上界规划，不擅自改口径。

## 4. 唯一下一实验：D，冻结模型的盲考试

### 4.1 目标与冻结规则

本实验只回答“选定候选相对6.445对应基线的0.101是否能在新样本上复制”，不估计训练算法跨种子收益。**零新训练，CPU推理，显式禁用CUDA；本次审阅不执行。**

- 主比较固定为s12中旧面板6.344对应的那一个checkpoint与6.445对应基线；二者需登记真实checkpoint路径、hash、训练步数、推理温度、move guard、引擎/数据版本及完整配置后才可开考。若该历史checkpoint不存在，不能拿末尾模型冒充，实验须重新预注册候选身份。
- s10和s13可做探索性旁证，但不并入主检验，也不按exam结果重新选赢家。仅一个主比较，双侧α=0.05；后续另开候选必须用新exam或预先校正多重比较。
- 固定7席、人类10k+目标群体、512旧面板相同注入语义、auto规则、英雄/种族/版本与座位采样权重。旧420000面板降级为development；新seed不能与已用420k–720k、910k审计面板混用。

### 4.2 exam库与真正的隔离

- 按**来源玩家、源对局/录像、整局所有turn、重复/近重复战团连通分组**切分；同一源组全部属于train/dev/exam之一。不能逐帧随机切分；缺玩家身份时至少按源对局分组，并明确跨玩家泛化不可验证。
- 仅保留与唯一引擎基线兼容的记录；跨版本记录须可审计映射或分层单报，不得把版本变化误判模型进步。记录每个turn、强度分位、英雄/流派的覆盖率；auto分位规则预先冻结，不能看候选成绩后改分桶。
- **已经被训练使用过的源组不能事后“划为独立exam”**。若旧库全被训练看过，需新采集未接触的源组；否则本实验只能回答“固定旧库上的新RNG泛化”，不能声称独立库泛化。来源不足是评测结论的限制，不是启动新训练的理由。
- 建议至少200个独立源对局组，且所有主要turn/分位有覆盖；200不是普适功效保证，最终由簇间方差决定。不足则降低结论外推范围。冻结manifest、来源排除清单及hash，考试结果在冻结前不可见。

### 4.3 规模与停止规则

1. **成本/方差pilot：1,024个新配对场景**，与正式exam源组分离；只向决策者披露耗时、失败率、配对方差和源组聚类方差，不披露带符号均值。不得据pilot选模型。
2. 正式目标**32,768对局场景**，即每模型32,768局、共65,536局。覆盖保守独立估计下约90%功效。用pilot的方差上界及层级仿真事前检查功效；必要时一次性上调至**65,536对**，不得按显著性边跑边加。
3. 最多8 CPU worker，先测CPU秒/局并报总机时；若预算不可接受则回退为“不足以裁决”，不降样本后把失败解释为无效。不占GPU，不启动或停止任何既有训练任务。
4. 主分析：逐局配对差值、95%CI；对重复源组与游戏场景做适当多层/多向聚类bootstrap或层级模型，报告普通配对结果与源组稳健结果。一个游戏含多个源组时不能随意只认一个组。若有效源组太少或功效不足，结论为未决。
5. 无中途显著性查看；固定最终样本一次检验。非法动作/引擎错误不静默删局：记录配对失败原因，修复协议后两模型同条件重跑；差异性失败或机制不一致直接判实验无效。

### 4.4 门禁与回退

- **真实改善门禁**：主比较 `G` 的源组稳健95%CI下界>0，支持该冻结checkpoint真实改善；点估计≥0.10可称达到预定目标幅度。若要声称“至少改善0.10”，必须CI下界>0.10，不能偷换。
- **可忽略差异门禁**：90%CI完全包含于[−0.10,+0.10]，支持当前候选与基线实践等效；只说CI跨0则为未决。
- 真实改善若只有0.10，仍不能称“达到真实强度”；要联合下节过程指标判断。旧面板赢家在新exam消失，优先归因选点/面板泛化，而非宣判某种优化机制失败。
- 若失败，保留原基线及旧库；不根据本次exam调参再考同库，exam转为已见开发数据。A/B/C不是本轮的附加训练臂。

## 5. 预注册指标：名次之外必须报告什么

**唯一主终点**：human平均rank差值。top4、win和bot指标是次要终点，不以其中任意一个显著替代主终点。

固定t=8/10/12/15，在相同对局场景报告：

- 学习者存活率 `P(T_alive≥t)`；全大厅存活**玩家人数**均值/分布；学习者出局回合。另报战斗后存活**随从数**，不得与玩家人数混称。
- 原项目同口径的战团强度 `S`；冻结公式、EOT测量位置及真实参考分母。按turn/版本匹配真实exam的强度中位数，报告 `S_learner / median(S_human|turn,stratum)` 的分位数与配对变化；不是拿“出局时800”直接除以“真实t15的26,516”。
- 同时报告**存活条件下强度比**与**全起始局口径强度比**（t前已死记0），避免只剩少数强局造成幸存者偏差。t15样本不足必须显示n/CI，不能靠条件中位数补成全体进步。
- `tier≥5@t15`同样分条件/无条件口径；实际遇人类战团比例、注入拒绝/缺字段、每turn动作数与move次数也必须列出。

过程验收建议预先锁定：t12、t15的无条件强度比相对基线点估计至少提升20%，且各自改善CI下界>0；存活率非劣界−2pp（CI下界>−2pp）。这些是**工程进步门禁，不是已知的真实强度阈值**。按固定顺序主rank→t12强度→t15强度→存活非劣检验，未通过则后续只描述。统计检测到rank改善但强度/存活门禁未过，只能称“小幅名次改善”。

## 6. 训练种子：不能用更多评测局替代

本轮D可验证两个固定模型，但不能验证“训练方法平均改善”。后者需要同配置、同预算、同选择规则的独立训练重复；不同配置的s10/s12/s13不能充数。

未来确需算法比较时，先设计**至少5对训练种子作为方差pilot，计划至少10对**，每对有匹配初始化/训练随机种子控制、但不同种子对独立；全程固定checkpoint时间，不选每run最佳。设种子层差分标准差为τ，单对评测误差方差为v，则正态近似：

`K ≈ (1.96+0.84)² (τ²+v) / 0.101²`（80%功效）；90%用10.51替换7.85。

忽略v时，τ=0.05/0.10/0.15/0.20分别约需2/8/18/31对（90%约3/11/24/42对）；小K必须使用t分布/层级仿真，数字会上升，2–3对不作为可靠方差估计。**因此不存在仅凭512局SE就能回答的固定训练种子数**。建议先把每模型评测误差压到不主导种子方差，再扩K；最终报告种子级CI，而非把所有局拼在一起伪造巨大的独立n。本轮不授权这批训练。

## 7. 止损：停止的是什么，不是什么

现在可以停止的决策是：**不再凭旧512局面板的低点加码同类长训、容量扫描或补字段工程**。这不等于要求杀掉在跑任务，也不等于s13剩余100M已经被证伪。

“当前PPO+准完整库路线在给定预算内无实用进展”的正式止损需同时满足：

1. D通过数据/统计有效性门禁；排除旧面板选点、泄漏、版本和幸存偏差。
2. 对现行最强固定配置，预定预算上限**120M decisions/run**，按上节具有足够功效的独立种子评估；平均rank改善的95%CI上界<0.10，且t12/t15无条件强度比相对提升的95%CI上界<20%。这些是“排除了有意义收益”，不是“p>0.05”。
3. 在相同turn可比口径下，强度比仍处3–15%量级，未达到预先约定的人类参考带。真实强度应另以完整状态、相同版本且无泄漏的战斗/对局校准定义；当前注入代理不能认证真实MMR。

满足后应停止该**预算内、该数据和优化配置族的继续堆算力**，而非宣布所有PPO不可能成功。若资源不足以完成种子功效要求，可作经济止损，但报告必须写“证据不足且继续投资不划算”，不能写成科学证伪。

## 8. 最终裁决

**结论不是“已经到头”，而是“当前证据无法把约0.10名次变化从噪声与选点效应中分离；真正大的强度缺口则十分明确”。唯一下一实验为D，先冻结s12候选与基线，在真正隔离的源组exam上做32,768配对场景评测，再决定是否值得改变信用分配或引入搜索监督。**
