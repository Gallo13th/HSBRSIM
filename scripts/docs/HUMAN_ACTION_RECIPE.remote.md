> 纯 CPU 分析：`data/firestone_replays/firestone_recent_actions.jsonl.gz`（149,166 条真实操作 / 500 局 / 6,852 game-turn）

## 0. 数据限制（先说清）

- **`gold` 字段 = 每回合的收入上限（max gold，含 max-gold 加成），不是实时余额**：6,258/6,852（91%）的 game-turn 里该回合所有动作的 gold 值恒定；违背"每花 1 金余额就降"的实时余额语义。
- 因此**无法**用 `gold_end − gold_start + 花费 − 卖出` 反推逐回合现金流；本报告用 **`income(t) = 该回合观测到的 max gold`** 作为收入，花费由动作单价重建（买随从 3 / 法术按卡价 / roll 1 / 升本 5-7-8-11-11-10 / 卖回 1）。
- 491 局在 t12 前结束；各回合局数见 JSON。

## 4. 结论：人类靠什么在 t9 同时做到 tier5 + Σ546

**机制排序（每条附数据）**：

1. **卖牌周转（sell churn）——第一机制**：t7 起人类每回合卖 2.0→8.2 张（我们 1.6→2.4），**卖牌回收金币**（每张 +1 金）后再投入 roll/买高 tier。卖牌量在 t9–t12 是我们的 **2.4–3.5 倍**。
2. **多刷新（roll）——第二机制**：t7 起 1.5→6.9 次/回合（我们 0.8→1.8），**用卖牌的钱滚动找高 tier 牌**；roll 花费 t12 达 6.9 金/回合。
3. **买高 tier、少买便宜牌**：t9 人类买牌 2.25 张但 tier 分布 t4–t6 占 84%，我们 3.17 张但几乎全 t1–3 ⇒ **同样的金币买"更贵但更强"的牌**（body 质量而非数量）。
4. **英雄技能持续投入**：0.30–0.43 次/回合（我们 0），t1 就有 0.30——部分英雄技能给钱/给牌，是额外金币/牌源。
5. **升本更早**：t2 人类 0.86 次升级/局（我们 0.02），t4 0.49、t5 0.64——**t2 就升 tier2**，之后每回合的升级费因 turn 折扣更便宜；我们的升级集中在 t5–t8，t9 才到 tier4。
6. **收入略高**：t8 10.5 / t9 10.8 / t11 11.5（max-gold 加成），但只有 +0.5~+1.8/回合，**不是主因**。

**一句话**：人类不是"攒钱升本"，而是**高频卖牌+刷新把金币周转起来，买更贵的高 tier 牌**；我们则是"少卖少 roll、买便宜牌"，所以 t9 tier 4、Σ 只有人类的 1/3。
