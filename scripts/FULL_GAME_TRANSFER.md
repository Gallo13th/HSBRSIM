## 2. 归因（动作直方图 + 指标联合读）

动作分布**形状**与 s14 并不离谱（`buy 22%` vs 15%、`play 31%` vs 30%、`target 17%` vs 19%），
所以不是「不动了」。真正的断裂有三处：

1. **买了不涨**：`buy 22%` 却 t12 = t15 = **62**（板子从头到尾 1–2 张 1 星），r12 = 1.00。
   沙盒里「买法术→打载体」能直接变成身材（载体 + buff 农场），完整对局里这条链**不闭合**
   ——法术要先有载体、载体要 tier/回合，早中期只有空放。
2. **经济/节奏差一个档**：沙盒 `fixed20`（每回合 20 金、无伤害、无对手）⇒ 每回合能连买 4–6 次、
   快速升本；完整对局 3–6 金/回合 + 有战斗 ⇒ 决策/局从 **155 → 56.9**（它每回合 1–2 步就 EndTurn）。
3. **放大器被层级门槛挡住**：Titus/Drakkari 是 **tier 5**、Gatekeeper **tier 6**；完整对局里它
   `tier p50 = 4` ⇒ 商店里**根本刷不到**那几张牌（沙盒里 20 金/回合能稳定上 5–6），
   所以 amp 从 8.33 掉到 **0.04/局**。

⇒ 一句话：**沙盒把「升本 + 买放大器」的成本压到接近 0，策略学到的是「廉价复利」；完整对局里
这两个前提都不成立，于是退化成「买法术、空板、活到第 15 回合、稳定第 8 名」。**

## 3. 下一步（供决策，未执行）

1. **先对齐经济再谈迁移**：沙盒训练必须用「完整对局的收入曲线」（3–6 金/回合 + 升本成本），
   而不是 fixed20；否则学到的策略在真实成本下没有意义。
2. **把「升本」当显式目标**：tier 4→5/6 是放大器可购买的前提，应该在奖励里给升降本信号
   （现有 `log_strength` 只在身材上，不管能否摸到核心牌）。
3. 若要继续蒸馏：状态必须来自**目标分布**（完整对局里能活到 t12 的策略，如 s14），
   而不是来自沙盒策略自己访问的状态（本轮的 200 局已经证明那些状态是"空板局"）。

## 5. task-13：经济对齐 + tier 奖励（**仍不迁移；但 tier 门槛被打开了**）

**① 真实金币曲线**（`runs/full_distill/gold_curve.json`，40 局 s14，**只统计存活回合**）：
t1..t13 = **3,4,5,6,7,8,9,10,10,10,10,10,11**（p10/p90 在 t≥9 有 ±2 的抖动）。
沙盒原来用 `fixed20`（**每回合 20 金**）＝ 真实收入的 **2–6 倍**，这是「沙盒能刷 8 张放大器、
完整对局 0.04 张」的第一个根因。已加 `--gold-profile`（默认空＝旧行为，逐位等价），
并验证 `income_for_turn` 逐回合命中该曲线（旧路径 20/回合不变，沙盒契约测试 43 项全绿）。

**② tier 奖励**：`--tier-reward-coef`（`r += coef·(tier_t − tier_{t−1})`，默认 0 = 不变）。
用 0.1（t1→t6 总共 +0.5，仍在 value 头 tanh 的可用区间内）。

**③ 重训**：从 `telescope@310k` 起、telescope 奖励 + tier 项(0.1) + 对齐经济，300k decisions
（lr 3e-6、value-warmup 100 只训 head、β≡0.1、退化早停）。训练侧 `entropy 0.80→0.81`、
`approx_kl ≈2e-4`，**没有退化**。

**④ 评测**（greedy）

| | 沙盒（对齐经济，24 局） | 完整对局（100 局） |
|---|---|---|
| 起点策略 `telescope@310k` | Σ 516 / amp **2.00** / r12 1.89 | Σ **62** / tier 4 / amp 0.04 / 名次 7.86 |
| 对齐后 `rv_econ_tier` | Σ **257** / amp 1.50 / r12 **1.54** | Σ **22.5** / **tier 5** / amp 0.07 / 名次 7.97 |

判据「完整对局 Σ ≥300 且 tier p50 ≥5」：**tier ✅（4→5）、Σ ❌（62→22.5）**。

**结论（两层）**：
1. **tier 门槛确实被打开**：tier p50 4→**5**，说明「用奖励把策略推上 t5」这件事可行且成本低。
2. **Σ 反而更差，说明「经济对齐」不是关键变量**：把金币从 20/回合降到真实的 3–11 后，
   沙盒最优解变成「少买、留钱」——**沙盒 Σ 的天花板本身就低**（无战斗/无伤害/无对手，
   多买一张随从在沙盒里不会变成名次）。于是策略在完整对局里更保守：决策/局 56.9→43.5、
   t15 Σ 62→22.5。**「沙盒经济贴完整对局」不足以带来迁移**，定论成立：
   **沙盒缺的不是收入曲线，是战斗/名次这一层回报**。

**因此 A2 蒸馏仍然不做**（负结果，写进本文件即可）。下一步若还要走这条路，需要的是
**带战斗的轻量环境**（或直接进完整游戏做 RL），而不是继续调沙盒经济/奖励系数。
