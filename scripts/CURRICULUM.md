# 课程学习（curriculum learning）设计草案（2026-11-05）

> 状态：**草案**。当前先跑 37.0.2 的固定配方基线（B02）；课程学习作为下一段的单变量实验，
> 一次只动一个杠杆。

## 1. 目标与判据

- 主判据：**8-bot 面板 mean_rank / top4 / win**（训练配置 move_guard=1，≥128 局）；
  以及「长且强 bot 局 win」（turns 与 bot 终局强度都在 top 25%，≥128 局）。
- 参考判据：canonical human 面板（96 局 / seed 520000）；只作 sanity，不作为唯一成败。
- 机制判据：entropy / approx_kl / anchor_kl、`kl_early_stopped`；不允许坍缩。

## 2. 可用杠杆（按改动成本排序）

| 杠杆 | 现状 | 课程做法 | 风险 |
|---|---|---|---|
| **对手难度（人类盘面分位）** | canonical 固定 p75；训练注入 3 席 p0.9 | p50 → p75 → p90，按 bot 面板 rank 阈值升档 | 只改对手，不改奖励；最安全 |
| **人类盘面席位数 / p** | 训练 3 席、p0.9 | 2 席 p0.7 → 3 席 p0.9 | 强度跨度小 |
| **大厅种族数 / 池** | 5 种族全池 | 早期限 3–4 种族 → 5 | 改变策略分布，需单测 |
| **对局长/强权重** | 仅评测加权 | 训练 PPO per-episode 权重（长度+bot 强度） | 偏置风险，需 n_eff 监控 |
| **对手 league** | 仅 bot/人类盘面 | 历史 checkpoint 联赛，按胜率采样 | 最复杂，先不做 |
| **奖励 shaping** | 纯 rank utility | 终局强度系数 0→小值→0 | 与 P2 混用会混淆 |

## 3. 推荐路线（单变量）

- **B02（当前）**：37.0.2 + 固定配方（p75 / 3 席 p0.9 / 纯 rank reward）+ 每 10M bot 面板。
  这是新 patch 的基线，不混课程。
- **B03（对手难度 ladder）**：以 B02 的 10M 曲线为基线，训练内人类盘面分位按 bot rank 门控：
  - 起步 p50；当 8-bot `mean_rank ≤ 2.0` 且 `top4 ≥ 95%` 连续 3 个 10M 点 → 升 p75；
  - p75 下再次满足 → p90；不满足则降回上一档。
  - 其余配方逐字不变；比较 B03 vs B02 的 128 局 bot 面板与长且强 win。
- **B04（长度+强度加权）**：在 B03 稳定后，加 per-episode PPO 权重（`α=β=0.5`，
  loss 加权、均值 1），目标是把「长且强 bot 局 win」从当前 0–25% 拉过 50%。
- **B05（可选，league/self-play）**：只有当 B03/B04 仍无提升时再做。

## 4. 监控与回退

- 每个 10M 点：canonical human + **8-bot 面板** + 长且强子集；`points.jsonl` 同时记录。
- 回退：任一阶段 20M 内 bot rank 退化 >0.3 或 entropy<0.65 连续 10 iter → 回上一档/上一 checkpoint。
- 所有课程参数写进 `meta.txt` / `summary.json` / `DECISIONS`，保证可复现。

## 5. 与其它工作的边界

- 引擎/数据升级（37.0.2）单独一个 commit，不与课程参数混。
- P2（anchor 调度）与课程学习**分开做**；一次只改一个变量，否则无法归因。
- 课程学习不改变动作/观测/奖励数学，只改对手分布或样本权重。
