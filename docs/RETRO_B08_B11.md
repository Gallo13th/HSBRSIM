# 复盘：B08 → B11（2026-11-07 ~ 11-08）

> 目标：让模型学会"复利阵容"（乘算放大器 + 成长引擎 + 成对），同时不得牺牲对局强度。
> 结论先行：**升本问题解决了，复利还没解决；本轮最大工程收获是找到并修掉了一个长期空 mask 死锁。**

## 3. 为什么复利没有自然诞生（本轮最重要的技术结论）

四条证据链：

1. **升本已不是瓶颈**：B08 把 `tier≥5@t15` 推到 100%，6 本盘面里依然没有放大器 → 不是"上不去"。
2. **放大器本身不涨战力**：铜须/达卡莱/提图斯当回合几乎不提供属性，它们的收益要 2–4 回合后兑现；终局单标量 + GAE(λ=.995) 无法给"当回合买它"正向 advantage。
3. **标量目标会被"加法"满足**：B10 的 ceiling 头把 t18/t20 强度拉高 44%/75%，但那是靠"单卡更肥"（加法），不需要乘法结构 → **目标函数选错了**。
4. **模仿也不行**：B09 用 6k+ MMR 人类示范（含只高本 tier≥5 的 149k 样本）训练，放大器 0.64% ≈ 基线 → 人类数据里"该买哪张核心"这个知识**没有以动作级形式存在**（人类也在大量非复利局里打）。

## 5. 下一步的三个选项（供决策）

| 选项 | 做法 | 成本 | 预期 | 风险 |
|---|---|---|---|---|
| **A. 补观测（P5）** | 注入"成长斜率"（4–8 回合 EMA/斜率）与"对手 Δtier"，让模型**看见**复利的收益曲线 | 观测维度 +~30，需重训 | 中高：把"看不见的延迟收益"变成可观测特征 | 破坏现有 checkpoint 兼容（需从头或热启动重训） |
| **B. 用搜索/蒸馏（ExIt）** | 用 MCTS 或"终局回放的 best-of-N"生成"哪些早期动作导致更肥终局"的标签，做策略蒸馏 | 采集成本 ×N | 中：把搜索当 teacher，绕开信用分配 | 慢（每步搜索代价），但不需要改观测 |
| **C. 强化买卡规则（B11 继续）** | 把规则从"必须买"扩展为"必须买 + 必须成对 + 必须围绕放大器铺同族" | 低（~1 小时实现） | 低–中：能强行制造复利盘面，但学到的是"规则下的行为" | 过拟合到规则；关掉规则后可能回退 |

**建议**：先把 B11 跑完（它已在验证"强行喂核心卡能否长出复利"），同时并行准备 **A 的最小版本**（只注入"我方盘面强度斜率 + 最近 3 回合 tier 变化"两个特征），因为 B08–B10 已经证明"不给观测/不给稠密信号，复利不会自己出现"。
