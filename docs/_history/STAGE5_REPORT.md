## 4. 镜像对手课程（PPAI 硬门已过）

- 采样：`p50/p75/p90/max` 分位（本阶段用 **p75**），seat **每回合随机抽 2 个非 learner 座位**，p 从 0.1 ramp 到 0.3；
- 硬门：`scripts/mirror_hard_gates.py`，15 格 × 1000 seeds = 15k 局、**294,143 次注入**，timing/重复 EID/池守恒/invariant/非预期拒绝全 **0**，拒绝事务 **94,596/94,596 = 100%** 字节一致；
- 难度探针（自采 711 帧）：arm0 2.00 → arm2 **4.00** / arm3 3.95（全部 40/40 终局），证明镜像对手显著更强。

## 5. 动作序列辅助任务

- 定义：每个 `(game, seat, turn)` 的 action 集合 multi-hot(245)，BCE 辅助损失；
- `seq_loss` 从 **0.67 → 0.073**，系数 `0.02 → 0.05` ramp；采集开销 +0.4%，`--seq-coef 0` 与 HEAD 逐位等价。

## 6. BC（真实人类回放）就绪

- Firestone 1,000 局 → 308,944 条决策样本；卡表 99.95%、动作映射 93.88%；
- 过滤后 183,245 条（MMR≥6000、白名单、类别平衡）；`--bc-coef` 默认 0 且逐位等价；
- 从已训练 ckpt 起 BC CE 初始 14–18（部分观测 OOD），建议 s6 从 5e-4 起 ramp 到 5e-3。

## 7. 可回退性

- `--mirror-p 0`、`--seq-coef 0`、`--bc-coef 0` 均验证与关闭时**逐位等价**；
- `--compile-train` 编译失败自动 warn 并回退 eager；
- 早停/回滚：`--eval-stop-mean-rank` 异步判定、iteration 边界生效（本阶段未触发）。

## 8. 结论

100M decisions（2180 iteration，wall ~8.07s/iter，中位 47,690 decisions/iter ≈ 5,907 dec/s）把 C0 mean rank 从 2.279 降到 **1.975**、吃鸡 31.4% → **43.4%**，未见面板同样成立（2.459 → 2.047）。
同时完成吞吐 2.1×、镜像硬门、序列辅助与 BC 数据管线，全部默认关闭可回退。
