# B11：复利买卡规则（v1→v4）与"放大器不可用"的发现

## 版本演进

| 版本 | 规则 | 结果 |
|---|---|---|
| v1 | 无条件：商店出现核心卡就屏蔽其它购买 | 训练崩溃/tier 掉，撤回 |
| v2 | 条件式：已承诺阵容→必须买；开局对放大器软偏置；六条恢复条件 | 放大器仍 0 |
| v3 | 目标只留 MULT+GROW；`max_copies=2`；开局放大器**硬强制** | 10M→150M 放大器仍 **0 张** |
| v4（当前） | **目标改为"当前卡池里真的会出现"的 GROW+ENGINE 卡**（`bias_available`） | 运行中 |

## 关键发现（v3 失败的根因，2026-11-09）

B11 在 10M/20M/50M/100M/150M 五个点、共 221 个前二盘面里，**布莱恩·铜须 / 达卡莱附魔师 /
提图斯·瑞文戴尔 一次都没出现**。探针进一步确认：

- 4 局 957 个决策里，商店**从未出现过任何一张放大器**（`mult_in_shop = 0`）；
- 引擎 `universe`（本局卡池）里，这三张卡的**所有变体（含金色）都不存在**；
- 抽样 40 个大厅：三张放大器可用率 **0%**；77 张人工整理的核心卡里只有 **36 张**可用率 ≥40%。

原因：**当前规则集的卡池按大厅种族过滤**，而无种族的 T5 随从（Titus/Drakkari/Brann 都是 T5
无种族）**不在池里** —— "买放大器"这条路在本引擎里不存在。

## v4 的规则（在 v2/v3 框架上换目标集）

- 目标集合 = `data/comp_cards.json` 的 **`bias_available`**：GROW+ENGINE 里可用率 ≥40% 的卡
  （63 张；生成脚本 `tools/gen_comp_cards.py` 抽样 40 个大厅自动计算 `avail`）。
- 判据不变：已承诺阵容→必须买；开局对成长核心软偏置；六条恢复正常条件；场上核心不许卖。
- 参数：`--comp-buy-include GROW,ENGINE`、`--comp-buy-max-copies 2`、
  `--comp-buy-mult-force-health 15`、`--comp-buy-mult-force-turn 12`
  （MULT 已为空，前两条自动失效，保留以便换规则集）。

## 判据

放大器卡位 ≥3% —— **该指标已作废**（放大器不可得）。改用：

| 指标 | 基线（B10@50M） | B11 目标 |
|---|---:|---:|
| 可用成长卡（`bias_available`）在终局盘面的卡位占比 | ~0% | ≥20% |
| 每唯一卡张数（成对/金色） | 1.05–1.09 | ≥1.20 |
| T5+ 卡位占比 | 28–38% | ≥45% |
| 96 局 bot rank | ~1.5 | ≤1.60 |
| 96 局 human rank | ~6.0 | ≤6.00 |
