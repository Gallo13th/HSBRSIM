# 奖励信号与观测信息审计（B07 配置）

> 目的：解释「为什么模型越收敛越偏向稳健前中期，而不是"尽早启动指数成长核心"这条真实
> 对战的强势路线」，并列出可改的点。事实来源：`runs/az_stage300m_b07/BLOCK_INFO.txt`
> 的完整命令行、`hsbg/env/obs_std.py` 的块定义、`docs/TIER_TARGET.md` 的历史 A/B。

## 0. 事实更正（卡牌）

`夺金健将`(BG32_236) 的文本是「圣盾。本随从始终为金色，但不会获取三连奖励」——
**它本来就是金色**，所以"终局金色率 100%"不代表模型主动三连它。同理
`拔线机`(BG29_611) 是「圣盾。亡语：召唤一个 1/1 微型机器人」的 1 本圣盾体。
两者都不是"指数成长核心"，而是**前中期性价比极高的稳定牌**——这与"模型擅长稳健
前中期运营"完全一致，也进一步说明它没走到高本核心里去。

## 1. 奖励信号：现在只有一个终局标量

B07 的奖励相关参数（其余全部为 0）：

| 参数 | 值 | 含义 |
|---|---|---|
| `rank_utility_coef` | **1.0** | 唯一奖励源：终局名次 → utility |
| `terminal_strength_coef` | 0.0 | 不加终局强度 |
| `shaping_coef` / `tier_target_coef` | 0 / 0 | 无势函数、无升本目标 |
| `step_penalty` | 0.0 | 每步无小惩罚 |
| `survive_t12/strength/late_*/win_only/upgrade_*` | 全 0 | 无任何中期通道 |
| `gamma` / `lam` | 1.0 / 0.995 | 无折扣、GAE λ |
| `entropy_coef` | 0.001 | 弱探索 |

结构上：**一局 ≈ 143 条 learner decision（B07：55k decisions / 384 局）只拿 1 个标量**
（`utility_from_rank`），整条轨迹的所有 decision 分享同一个 advantage 的符号与量级。
GAE 的衰减 `λ^k`：一个 t5 的决策到终局还有 ~110 步，权重 `0.995^110 ≈ 0.58`——信号不是
"消失"，而是**无法区分"早升本"和"晚升本"**：两者的 advantage 都来自同一个终局结果，
差别只体现在 critic `V(s)` 上。

## 2. 为什么这会把策略推向"稳健前中期"

1. **信用分配全靠 critic**：要学"t5 花 9 金升本、t9 才回本"，必须让 `V(t5, 4本, 满场)`
   显著低于 `V(t5, 5本, 少一怪)`。300M decisions 内 critic 学到的主要是
   "血量/盘面强度/存活"这类**与终局名次强相关、方差小**的代理 ⇒ 策略被推向"现在就变强"。
2. **方差偏好**：指数路线的收益分布是"多数局亏、少数局爆"，终局标量奖励下其梯度方差
   远大于稳健路线；PPO 在固定 KL 预算下自然选低方差方向 ⇒ 收敛到局部最优。
3. **场地压力**：B07 训练场地是 **5 席 p0.90 人类盘面 + full 保真 + 按回合曲线（末段 p90）**。
   早期就贪本 → 立即掉血 → 多数局在 t9–11 出局 → 负 advantage。**这条路在训练场里被系统性惩罚**。
4. **探索不足**：entropy 已降到 0.46，且没有"策略条件"（单峰策略），无法并行尝试
   "稳健"与"贪本"两种模式。
5. **历史证据**：`docs/TIER_TARGET.md` 的 A/B 显示 `coef=1` 完全不动 tier，`coef=10` 才把
   t12 的 `tier≥5` 从 28% 拉到 50%（但 human 面板没改善）⇒ **奖励通路是通的，卡在信用分配**。

## 3. 观测信息：有什么、缺什么

现在每步观测 = 3227 floats + 124 张卡槽：

| 块 | 形状 | 内容 |
|---|---|---|
| global | 53 | turn / gold / **gold_next_turn** / **tier** / **upgrade_price** / refresh_price / health / armor / power 可用性 / trinket_count / board_len / hand_len / next_is_ghost … |
| pending_kinds | 9 | 当前 pending 种类 one-hot |
| board_minions | 7×31 | 每个随从：卡 id/攻血/关键词/race/层数… |
| hand_items | 10×40 | 手牌 |
| shop_items | 8×40 | 商店（当前可见） |
| choice_items | 16×40 | discover/choose_one 候选 |
| opponents | 7×9 | 每个对手：present/alive/health/armor/**tier**/placement/seen_board_len/is_next/is_last |
| opponent_boards | 7×7×31 | 对手上一场可见盘面（7 个随从） |

**做"升本换核心"这条路线所必需、但现在没有的信息**：

1. **商店分位概率 / 池子构成**：升本后的期望收益取决于"tier5/6 池里有什么、还有多少张、
   各分位出现概率"。现在只有当前 8 个可见商店位，没有概率与池计数。
2. **未来可得卡的集合表征**：网络只有 124 个"当前可见卡"槽位，没有"tier 5/6 全表"的
   表征通道 ⇒ 它无法在观测里"想象"高本核心。
3. **回合预算 / 死亡风险**：turn 有，但"以当前血量还能撑几回合"要自己推断，没有显式特征。
4. **自身成长斜率**：没有"我这套阵容每回合能涨多少"的显式量，而这正是判断
   "该贪本还是该稳"的关键。
5. **对手的升本轨迹**：只有当前 tier，没有历史（无法判断"全场都在贪本/都在稳"）。

## 4. 证据：我们离"指数路线"有多远

| 指标 | 我们的模型（B07@170M，448 局） | 真实 6k+ MMR 人类（`bc_samples`） |
|---|---|---|
| 终局 tier 分布 | T3 75 / **T4 273(61%)** / T5 85 / T6 15 | T5–6 为主 |
| tier5 到达回合 | t15 也只有 8–25% | **t8** |
| tier6 到达回合 | 极少（15/448 局终局到 T6） | **t9** |
| 强度曲线 | t14 见顶 ~1000–1200，之后不涨 | 持续增长 |

⇒ 我们比人类**晚 4 个回合、少 1–2 个 tier**。这不是"数值不够"，而是**路径不同**。

## 5. 可动的点（按性价比排序，均不需要禁卡）

| # | 方案 | 机制 | 成本 | 风险 |
|---|---|---|---|---|
| P1 | **修 tier-target 的信用分配**：惩罚从"回合第一条 decision"改为"该回合所有 decision 分摊 + 回合末未达标追加"，或直接给 `upgrade` 动作正奖励；coef 从 5–10 起 | 直接把"早升本"写进每步梯度 | 低（已有模块，改 ~30 行） | 可能诱导"无脑升本"（需与强度指标联合门禁） |
| P2 | **辅助价值头**：`--process-value-coef`（中期状态预测终局名次）+ `--strength-aux-coef`（预测终局强度） | 用监督把"延迟收益"拉近到每步，直接补 GAE 的短板 | 低（参数已有，需实现/接线） | 辅助目标权重过大会干扰主目标 |
| P3 | **场地软化课程**：前 30M 用 2 席 p0.75 board-only，再逐段升到 5 席 full p0.90 | 让"贪本"有机会活到验证收益 | 低（改 launcher 参数） | 前期学到的东西后期要重新适配 |
| P4 | **策略条件/双策略**：在观测或隐状态上加一个"稳健/贪本"条件，训练两种模式并用终局结果做选择 | 打破单峰局部最优 | 中（改模型+数据） | 工程量大 |
| P5 | **观测增维**：商店分位概率、池子计数、tier5/6 期望、自身 scaling 斜率 | 让"升本决策"有信息可依 | 中高（obs 版本 bump ⇒ 需重训/迁移） | 与现有 checkpoint 不兼容 |
| P6 | **λ 拉长**（0.995→0.999） | 让终局奖励对早期决策权重更大 | 极低（一个参数） | 方差增大，需监控 KL |

## 6. 建议的 B08 实验设计（两阶段）

**阶段 1（同时上 P1+P2+P6，一次到位，300M）**
- `--tier-target-coef 5`（惩罚分摊到回合所有 decision，`bonus` 提到 0.5）
- `--process-value-coef 0.1`、`--strength-aux-coef 0.05`
- `lam 0.999`
- 判据：**t≤7 到 5 本的比例**、`tier5@t12`、`tier6@t14`、96 局强度曲线 t14–18、
  768 局 rank（不得低于 B07）

**阶段 2（若阶段 1 的 tier 上移但 rank 没改善）**
- 说明"升本但盘面没变强"，再上 P3（软化场地，让贪本路线的收益能被真正验证）
- 若 rank 反而下降 → 回到 P2 单独（改信用分配但不强推升本）

**不做**：卡片禁用（会破坏运营）、观测增维（最后手段，代价最大）。
