# 阵容脚本 V2 规格

> 状态：已审定规格；本文只定义策略合同，不改引擎、代码或训练配置。卡牌 ID 以 37.0.0.255790 数据为准。

## 1. 一页结论

| 项 | 结论 |
|---|---|
| 优先路线 | **F 龙链**、**E-J 机械磁力/扩音**、**N 永恒亡灵**、**D 元素 Azerite**、**L-B 野猪宝石酒馆**、**G-K 野兽召唤** |
| 根节点 | 先看 t≤6 的龙链四张卡；否则按永恒亡灵、机械、元素、野猪、野兽的窗口与成对组件判定；t≥9 高本走通用高 tier；低血或 t≥11 保名次 |
| 目标 | 不是“看到核心就无条件转型”，而是在经济、血量、升本余金同时满足时锁定 scaling 链 |
| 人类证据 | 升本伤强度的说法被 15 局轨迹反驳（终局 tier6 Σ p50 4014，高于 tier≤5 的 955）；“三选二”成立；链卡上场中位 t11，不能硬压 t8 成形 |
| 量级参照 | 现有最强脚本 J 的 t15 Σ p50=249；用户手打链（塔蕾 `BG21_015` t2、诗人 `BG29_813` t4、奥术师 `BG36_245` t4、融合怪 `BG36_640` t6）t12 约 1.3k，单局峰值约 7.5M |

## 2. 六类脚本表

“核心”是收益/放大主件；“载体”是实际吃 buff 的单位；“enabler”是低 tier、决定链能否启动的关键卡；“filler”只要求类型多样性，不要求固定卡名。

| 类别（脚本） | 核心 | 载体（吃 buff 者） | enabler（低 tier 关键卡） | filler（只要求类型多样性） |
|---|---|---|---|---|
| **F 龙链** | 塔蕾 `BG21_015`、诗人 `BG29_813`、奥术师 `BG36_245`、融合怪 `BG36_640` | 融合怪；若未见则诗心龙/当前最大龙 | 塔蕾（t2 低 tier）、诗人与奥术师（t4 链入口） | 补足未拥有的种族类型，优先便宜且能存活者；不为凑名牌刷新 |
| **E-J 机械磁力扩音** | E 炫彩机器人/法术磁力链；J 机智机器人、多面无人机、扩音收益 | 选一只不卖的机械载体（优先炫彩机器人或机智机器人） | 微光机器人等早期磁力源；自动起床号为 tier6、火花破坏机为 tier5，属后续组件，不算低 tier | 机械之外的不同种族单位；只满足类型与战斗力，不抢磁力资源 |
| **N 永恒亡灵** | 永恒骑士 `BG25_008`、永恒召唤者 `BG25_009`；攻略“永恒大亨”与现实现囤积者须按 ID 核对 | 永恒骑士 | tier2 永恒骑士（争取回合4前）；召唤者是 tier5 后续核心，不算低 tier | 亡灵召唤、复生或临时强身单位；按类型多样性填位 |
| **D 元素 Azerite** | 活化艾泽里特 `BG28_707`、魔网浮灵、巴琳达、海藻护卫/铜须 | 活化艾泽里特或被酒馆法术持续强化的元素 | 地卜师/法术源（t4）、商贩元素、低费酒馆法术 | 元素优先，其余补不同种族；不因 filler 消耗升级金 |
| **L-B 野猪宝石酒馆** | L 宝石源/测绘员/鲁古格；B 邪能野猪人、干扰者、巴琳达 | 邪能野猪人或鲁古格；只能保留一条主载体线 | 测绘员、宝石生成/强化牌、得胜地卜师、低 tier 法术源 | 野猪人及尚未覆盖的种族，选择能承受宝石/酒馆强化者 |
| **G-K 野兽召唤** | G 甲虫/飞掠虫/狮鹫；K 深潜巨兽、老鼠头目、猛猿 | 深潜巨兽或甲虫；有召唤链时不卖 | 老鼠头目、低 tier 野兽召唤、狮鹫/进击入口 | 野兽召唤物与缺失类型；只追求多样性和战斗存活 |

## 3. 逐回合剧本（六类共用骨架）

| 回合 | 所有脚本的动作合同 | 路线差异 |
|---|---|---|
| **t1–2** | 只买最强低 tier；不为未来阵容买弱牌。t2 升本（除非致死风险），并保留可转型的便宜 enabler | F 可买塔蕾；N 可留永恒骑士；其余优先各自低费磁力/法术/宝石/召唤源 |
| **t3–5** | 保留已见 enabler；买牌优先补战力和缺失类型，禁止为找高 tier 核心连续空转 | F 保留诗人/奥术师入口；N 保留骑士+召唤者；E-J 留磁力源；D 留 Azerite 法术源；L-B 留宝石链；G-K 留召唤链 |
| **t4 饰品** | 有链卡或经济组件 → 放大成长；否则选择立即保命的战斗饰品，不为理论上限牺牲血量 | 链卡包括 F 四件、N 骑士/召唤者、E-J 磁力源、D Azerite、L-B 宝石源、G-K 召唤源 |
| **t6 饰品** | 饰品优先链放大器；若尚未有核心，取能立即提升战斗力/经济的保命项 | 放大器应作用于载体、法术/磁力、宝石、召唤或亡灵成长，不选无法触发的条件饰品 |
| **t8–12 转型** | 仅当 **核心在手 + 血量>20 + 升级后余 3 金** 才转型；否则保当前强度并按曲线升本 | 核心在手可锁载体，法术/磁力/宝石优先投载体；不强求 t8 上场，链卡上场中位可到 t11 |
| **t13+** | 撤下纯经济卡；滚刷新、找三连和最后缺件；升级回合不凑三连 | F 继续放大龙链；N 继续召唤/死亡计数；E-J 叠磁力；D/L-B 叠酒馆收益；G-K 叠召唤收益 |

## 4. 决策树伪代码

```text
if t≤6 and (塔蕾|诗人|奥术师|融合怪) in shop|hand → F
elif t≤4 and (永恒骑士+召唤者) → N
elif t≤7 and (机械核心+磁力 enabler) → E/J
elif t≤7 and (Azerite+法术源) → D
elif t≤8 and (宝石源+载体) → L/B
elif t≤8 and (野兽召唤+巨兽/甲虫) → G/K
elif t≥9 and tier≥5 → generic_high_tier
elif hp≤20 or t≥11 → preserve_rank
```

决策树只选择路线，不覆盖合法性检查；同一回合多路线命中时，按上到下优先，并以当前血量、余金和已锁载体复核。

## 5. 阈值与放弃

| 场景 | 规则 |
|---|---|
| 找伴生卡 | 只有 **核心≥1 且血量>20 且余金 ≥ 升级费+3** 才 roll；否则买战力/升本 |
| 核心窗口 | 核心到 t8 仍未见 → 退通用；不要用 t9–12 的贫金刷新证明“坚持” |
| 血量风险 | 血量≤20 立即停 roll，转保名次；t≥11 同样默认保名次，除非已有完整强链 |
| 升级与三连 | **升级回合不凑三连**；先支付升级并保留升级后 3 金，再考虑三连 |
| 载体 | 核心/载体永不因 filler 置换；无载体时不把关键 buff 随便打散 |
| 类型 | filler 只满足类型多样性；融合怪在 `one_minion_per_type` 中只算 1 族，不能把“全类型”误判为已覆盖 |

## 6. 实现差距与边界

| 差距 | V2 要求/影响 |
|---|---|
| hybrid 默认不足 | 当前 `comp_scripts.py` 的 hybrid 只由 `comp_action` 管核心/法术，经济交给 bot，不能强制 hp、roll、升本门槛；**F 必须独立走纯脚本 `_recruit_f`** |
| 缺风险状态 | 需可读取血量、金币、升级费、升级后余金并执行上述阈值；现有“看到核心即买”会过早转型 |
| 缺 enabler 链 | 需要显式表示低 tier enabler、触发效果及其依赖，不能只用核心卡集合 |
| 缺对手信息 | 需要上轮对手阵容/战斗结果信号；用户打法是少量精准操作，不是盲目高频周转 |
| 缺战斗机制 | 亡语、进击、英雄技能及战斗内触发目前不能由招募期 hybrid 充分表达；G-K/N 的收益会被低估 |
| 类型统计失真 | 融合怪在 `one_minion_per_type` 只算 1 族；类型多样性检查必须与引擎语义一致，不能按全类型标签展开 |

人类数据的使用边界：人类 replay 更适合做对手牌面库/校准；赢家校准在论文口径带来约 **+6.3pp**，不应把少量动作轨迹直接当作已验证的 BC 教师。

## 7. 验收计划

| 脚本 | 规模 | 上报指标 |
|---|---:|---|
| F、E/J、N、D、L/B、G/K 各自 | 30 局 8bot + 30 局 5 席 p0.9 | t15 Σ p50、核心到手回合、载体 buff 占比、合法率 |
| 基准 | 现有最强 J：t15 Σ p50 **249** | 合法率不得低于现状 1.000；同时记录存活/名次，避免只看 t15 截面 |
| 目标参照 | 用户手打链 t12 约 **1.3k** | 先验证是否出现可持续 scaling，再与用户量级比较；不以单局 7.5M 代替 p50 |

验收必须报告每套的核心命中与放弃原因；若核心到手晚于生存窗口，应归因于时间/经济门槛，而不是继续放宽 roll。
