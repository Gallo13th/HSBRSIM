## 3. 结论

1. **真正的"数值膨胀源"是 拔线机 / 萨特唤魔者 / 夺金健将（+黑暗悖论体）**：
   在**同一终局 tier（T4）**内，含卡组的终局强度分别高 **+23% / +21% / +5.6% / +4.5%**。
2. **泰蕾苟萨 / 永恒骑士 / 青铜守卫在 T4 层内是负的**（−18% / −13% / −15%）：
   它们是"打不赢时的填坑牌"，不是膨胀源。这修正了"这几张都是成长核心"的直觉。
3. **夺金健将**：金色率 **100%**（模型每次都要三连它）＋第 1 名率 +6pp，是真实的强势卡；
   但它的强度增益（+5.6%）远小于**拔线机（+23%，且出场率最高 39%）**。
   因此"若因圣盾，则拔线机也该出现"的判断成立——**拔线机才是更主要的来源**。
4. 局限：以上是**条件相关**（赢得多的局更容易拿到/留住强卡），因果需要干预实验。
